# Guess-The-Number-Game

Gæt et helt tal fra 1 til 10. Du har ét forsøg, og spillet viser bagefter, hvilket tal computeren valgte.

## Kør spillet

Åbn en terminal i projektmappen, og kør filen med Python 3.

```sh
python Guess-the-number.py
```

På Windows kan du også bruge `py Guess-the-number.py`, hvis du har Python-launcheren installeret. Spillet bruger kun Pythons standardbibliotek.
